# Sudur

Приложение для обучения чтению Корана с нуля и его заучивания — для Android и iOS. Проверка чтения наизусть идёт прямо на телефоне, без интернета.

- **Техническое задание:** [`docs/tz/`](docs/tz/00-oglavlenie.md)
- **Правила для агентов:** [`AGENTS.md`](AGENTS.md)
- **Как работает команда и ветки:** [`docs/WORKFLOW.md`](docs/WORKFLOW.md)
- **Задачи:** [`docs/tasks/`](docs/tasks/README.md)
- **Решения по архитектуре:** [`docs/adr/`](docs/adr/)
- **Исследования:** [`docs/research/`](docs/research/)

## Состояние

Этап 1 — прототип главного экрана: одна сура, текст скрыт, слова появляются вслед за голосом. Задачи этапа — в [`docs/tasks/README.md`](docs/tasks/README.md).

## Структура

```
app/                 Flutter-приложение (создаётся задачей P01)
packages/            модули: договоры, логика на чистом Dart, сервисы
tools/               оценка качества на записях, сборка пакетов содержания
docs/                ТЗ, решения, задачи, исследования
```
