# eval

Оценка следования и проверки на наборе записей, на компьютере.

- **Владелец:** Opus
- **Задача:** [M01](../../docs/tasks/M01-eval.md)
- **ТЗ:** 5.3 (КЧ-01…КЧ-09), 5.5, 12.6, 14.2, 15.4 (М-01)

Правила: [`AGENTS.md`](../../AGENTS.md). Публичный интерфейс — только `lib/eval.dart`; внутренности — в `lib/src/`.

## Команда

Из корня репозитория:

```bash
dart run tools/eval/bin/eval.dart --corpus <папка с записями> --model <id модели>
```

В папке (вне репозитория) лежат пары файлов по ТЗ 12.6: `<id>.ann.json` — разметка, `<id>.<model>.asr.jsonl` — результаты распознавания. Отчёт пишется в `build/eval/<model>/report.md` и `report.json`.

| Параметр | Что это | По умолчанию |
|---|---|---|
| `--content` | JSON базы содержания из `tools/content_build` | `packages/testing/fixtures/content_p582_583.json` |
| `--normalizer` | `normalizer.json` пакета модели | встроенный (ТЗ 10.1) |
| `--thresholds` | `thresholds.json` пакета модели (параметры следования) | встроенные (ТЗ 12.4) |
| `--acceptance` | Пороги приёмки, группы, бутстреп, допуски CI | [`config/acceptance.json`](config/acceptance.json) |
| `--out` | Папка отчёта | `build/eval/<model>` |
| `--baseline` | Прошлый `report.json` для сравнения | — |
| `--ci` | Код выхода 1, если показатель упал сильнее допуска относительно `--baseline` (ТЗ 5.5) | — |

Записи, разметку людей и результаты распознавания настоящих записей в репозиторий не кладём.

## Как считается

1. Каждая запись прогоняется через `follow` так же, как на телефоне: результаты распознавания по порядку, те же параметры, в конце `finish()`. Результат одинаков при каждом запуске (бутстреп — с фиксированным зерном из конфигурации).
2. Для каждой записи считаются числители и знаменатели; показатели любой группы и выборки бутстрепа — из сумм.
3. Слова со статусом `unclear` не входят ни в один показатель.

| ID | Показатель | Числитель / знаменатель |
|---|---|---|
| КЧ-01 | Открыто на своём месте | открытые среди прочитанных чисто (`correct`, `repeated`) / прочитанные чисто |
| КЧ-02 | Открыто непрочитанное | открытые, которые не читались (`omitted`, `substituted` или нет в разметке) / все открытые |
| КЧ-03 | Точность | подтверждённые ошибки на настоящих ошибках / все подтверждённые ошибки |
| КЧ-04 | Полнота пропусков; замен — отдельно | пропущенные (заменённые) слова, на которых есть подтверждённый пропуск или замена / все пропущенные (заменённые) |
| КЧ-05 | Ложные тревоги на 1000 слов | подтверждённые ошибки не на настоящих ошибках × 1000 / прочитанные чисто |
| КЧ-06 | Отказы | слова в событиях `unverified` / все слова; только записи нормального качества (`normalNoise`) |
| КЧ-07 | Самоисправления | слова `selfCorrected` в событиях `corrected` / все `selfCorrected` |
| КЧ-08 | По группам | все показатели по каждой группе; точность ≥ порога в каждой |
| КЧ-09 | Интервалы | бутстреп **по людям**: выборка людей с возвращением |

Подробности сопоставления:

- Считается последнее состояние каждого события. Подтверждённая ошибка — `confirmed` (или `disputed`) у пропуска, замены, лишнего слова, перескока.
- Пропуск или замена настоящие, если хоть одно их слово размечено как `omitted` или `substituted`. Подтверждённая ошибка на слове `selfCorrected` настоящей не считается: по ПО-05 там должно быть «исправлено».
- Лишнее слово и перескок сопоставляются с разметкой по времени (`insertions`, `jumps`) с допуском `timeToleranceMs`.
- Нет знаменателя (например, в чтении нет ни одной ошибки) — «нет данных», а не 0% и не 100%.

**Режим выпуска (ТЗ 5.3):** Г — не прошли КЧ-01 или КЧ-02; В — не прошли (или нет данных) точность или ложные тревоги; А — прошло всё, включая каждую группу; иначе Б.

**Сравнение:** изменение каждого показателя в процентных пунктах (для КЧ-05 — в единицах на 1000). Допуски для `--ci` — в `ciMaxDropPp` конфигурации: точность 1 п. п., полнота 2 п. п. (ТЗ 5.5) и предложенный мной КЧ-01 — 1 п. п.

## Формат разметки: что уточнено

ТЗ 12.6 оставляет `jumps` пустым массивом. Здесь элемент перескока: `{"fromWordKey": "78:3:1", "to": "79:1:1", "startMs": 5000, "endMs": 7000}`. Строка `.asr.jsonl` — поля `RecognitionResult` с теми же именами, `info.output` — имя значения (`uthmaniLettersNoDiacritics`).
