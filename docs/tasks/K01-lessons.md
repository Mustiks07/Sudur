# K01 — движок уроков курса «Учусь читать»

- **Агент:** Opus
- **Ветка:** `opus/k01-lessons`
- **Можно менять:** `packages/lessons/`, `packages/testing/` (тестовый пакет уроков); `pubspec.lock` — как следствие новых зависимостей
- **ТЗ:** 3.1 (УЧ-01…УЧ-10, типы шагов), 3.2 (ТД-03), 4.9 (пакеты содержания), 11.2, 12.3 («Пакет уроков»), 12.4 (`quizPassPercent`), 16 (языки интерфейса: ru, kk, uz, en)

## Зачем

Половина продукта — путь «Учусь читать»: от первых букв до коротких сур по порядку «Муаллим сани». Содержание уроков делает владелец, а движок должен уметь проиграть любой урок из пакета, посчитать мини-проверку и передать изученные навыки в план повторений.

## Что сделать

Пакет на чистом Dart: неизменяемые модели, чистые функции, время и случайность — внедрённые.

1. **Формат пакета уроков** (один пакет — один этап курса): JSON со схемой по ТЗ 11.2 — уроки, шаги всех типов V1, навыки, тексты на четырёх языках (ru, kk, uz, en), ссылки на звуки и картинки внутри пакета. Строгий разбор с понятными ошибками; версия формата.
2. **Типы шагов V1** из таблицы ТЗ 11.2: `explain`, `listen`, `repeatAndCompare`, `hearAndChoose`, `seeAndChoose`, `pairDiscriminate`, `findForm`, `buildSyllable`, `readSupported`, `findRule`, `quiz`. Для каждого — данные и подсчёт результата. «Произнеси, приложение проверит» — только интерфейс-заглушка: он зависит от испытания И-5.
3. **Состояния урока** строго по ТЗ 11.2: `locked → available → inProgress → quiz → passed`, при неудаче — повтор трудных шагов. Правила открытия: пройден предыдущий урок этапа или входное упражнение поставило старт дальше.
4. **Мини-проверка (УЧ-04):** процент из `quizPassPercent`; список трудных шагов для повтора.
5. **Навыки (УЧ-05):** урок перечисляет навыки; после прохождения — событие «навыки изучены», из которого приложение создаст единицы плана (планировщик — PL01, связывать их будет приложение). Повторение навыка: 3 вопроса помеченных навыком типов, оценка — все верно «Хорошо», одна ошибка «Трудно», больше «Забыл».
6. **Запись «Повтори и сравни» (УЧ-06):** движок сообщает, когда запись больше не нужна; сам звук не хранит.
7. **Тестовый пакет** в `packages/testing/`: по примеру каждого типа шага (УЧ-03), тексты и арабские буквы — заглушки `TODO_CONTENT` и идентификаторы навыков вроде `letter:ba`, без настоящего арабского текста.

## Готово, когда

- Каждый тип шага покрыт тестом и примером в тестовом пакете (УЧ-03).
- Тесты состояний урока, включая неудачу и повтор трудных шагов; тест «пройденный урок даёт навыки» (УЧ-05); тест порога мини-проверки.
- Тест формата: испорченный пакет даёт понятную ошибку, а не падение.
- Формат, анализатор, тесты, `check_deps` — зелёные.

## Не делать

- Не писать содержание уроков, объяснения и арабский текст — только `TODO_CONTENT` (правило 1 в `AGENTS.md`).
- Не импортировать Flutter и не трогать звук.
- Не менять `contracts` без ADR и согласия владельца.
