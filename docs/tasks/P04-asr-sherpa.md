# P04 — распознаватель на sherpa-onnx

- **Агент:** GPT-B
- **Ветка:** `gpt-b/p04-asr-sherpa`
- **Можно менять:** `packages/asr_sherpa/`
- **ТЗ:** 2.6 (РС-01…РС-07), 4.3, 4.4, 10.3, 12.3 (пакет модели), 17.5

## Что сделать

1. Скрипт скачивания моделей `Abdou/quran-asr-small` и `Abdou/quran-asr-tiny` с Hugging Face в `third_party_cache/` (файлы по карточкам моделей). Сборка **пакета модели** по ТЗ 12.3: `model.json`, `model.int8.onnx`, `tokens.txt`, `normalizer.json` (по таблице написания из карточки модели), `thresholds.json` (значения по умолчанию из ТЗ 12.4). Лицензия MIT — в `model.json`.
2. `SherpaCtcRecognizer` реализует `SpeechRecognizer` из `contracts`: `OfflineRecognizer` с CTC-моделью в формате zipformer CTC (как указано в карточке модели), 2 потока.
3. Работа в **долгоживущем изоляте** (ТЗ 4.3, 17.5): номер у каждого запроса, ошибки возвращаются как `Result`, порты закрываются при `dispose`.
4. Имитация потока (ТЗ 10.3): частичное распознавание открытого отрезка каждые `partialIntervalMs` по последним `maxPartialWindowMs`, окончательное — по `closeSegment`.
5. Тест телефона (РС-04): встроенный образец звука; результат — скорость обработки small и tiny.
6. Инструмент для компьютера: распознать WAV-файл и сохранить результаты в JSONL (формат ТЗ 12.6) — понадобится для `tools/eval`.

## Готово, когда

- На Android-эмуляторе или телефоне распознаётся эталонная запись (владелец даст свои записи суры 78).
- Тест, требующий модель, пропускается, если модели нет (CI не скачивает модели).
- Загрузка модели не блокирует интерфейс.

## Не делать

- Не коммитить модели и записи.
- Не исправлять распознанный текст.
