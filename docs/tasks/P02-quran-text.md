# P02 — текст, ключи, сходство

- **Агент:** Opus
- **Ветка:** `opus/p02-quran-text`
- **Можно менять:** `packages/quran_text/`
- **ТЗ:** 10.1, 12.2, 12.3 (`normalizer.json`), 17.2

## Что сделать

1. Интерфейс `QuranText` (ТЗ 10.1): слово по `WordKey`, диапазон слов, технический ключ слова для нормализатора, поиск последовательности по индексу.
2. Нормализатор из `normalizer.json` (формат ТЗ 12.3): удаление диапазонов Unicode, таблица замен, разделитель слов. Встроенный нормализатор по умолчанию — шаги ТЗ 10.1.
3. Сходство слов `similarity(a, b)` = 1 − Левенштейн / длина большего.
4. Индекс троек слов → места; поиск мест по распознанным словам.
5. Источник данных — интерфейс; реализация для v0 читает JSON суры 78 из `packages/testing/fixtures/` (P03).

## Готово, когда

- Тесты: канон после нормализации не меняется; каждое правило нормализатора проверено; поиск находит аят по 3 словам из середины; сходство на краевых случаях (пустые строки, одинаковые, совсем разные).
- Ключи нигде не возвращаются как «текст Корана» для показа.

## Не делать

- Не менять канон; не нормализовать регулярным выражением без таблицы.
- Не зависеть от Flutter.
