# D01 — производные данные: отрывки по умолчанию и похожие места

- **Агент:** Opus
- **Ветка:** `opus/d01-derived-content`
- **Можно менять:** `tools/content_build/`, `packages/quran_text/`, `packages/testing/`; `docs/adr/` — если понадобится решение
- **ТЗ:** 3.3 (УП-05), 3.4 (отрывки), 4.8, 12.2 (`passage_default`, `similar_pair`), 12.4 (`passageMaxAyahs`)

## Зачем

План повторений делит суры на отрывки, а упражнения и проверка перескоков опираются на пары похожих мест. Источник пар QUL пока без подтверждённых прав (ТЗ 6.1), поэтому пары нужно вычислить самим из текста Tanzil — это производные данные, сам текст не меняется.

## Что сделать

1. **`passage_default` для всего Корана:** 1–`passageMaxAyahs` аятов, длинный аят — отдельный отрывок, отрывок не переходит через границу суры. Правила, связанные со страницей (не больше половины страницы, без перехода через страницу), — только там, где есть разметка (ADR 0004). Что считать «длинным аятом» вне разметки, в ТЗ не сказано: предложи параметр с обоснованием и спроси владельца в PR.
2. **`similar_pair` из текста:** пары мест (диапазоны слов) с высоким сходством по ключам `quran_text` — повторяющиеся аяты, одинаковые начала и концовки, похожие обороты в разных сурах. `verified = false` у всех. Порог и правила — параметры. Отчёт: сколько пар, примеры по ключам слов, распределение по сурам.
3. **Запись в базу содержания** по схеме 12.2 и в JSON тестовых данных. Размер — в отчёте; если большой, предложи, что держать в приложении, а что в пакете.
4. **Проверки:** известные повторы находятся (например, все повторы рефрена суры 55 — по ключам слов, без набора арабского текста); пары симметричны и не дублируются; отрывки покрывают все 6236 аятов без пропусков и пересечений.

## Готово, когда

- Тесты из п. 4; формат, анализатор, тесты всех пакетов, `check_deps` — зелёные.
- В README `content_build` — как строятся оба набора, параметры и ограничения.

## Не делать

- Не менять и не писать арабский текст — только Tanzil через `content_build`.
- Не брать пары из QUL, пока нет подтверждённых прав.
- Пары не показываются пользователю как «проверенные специалистом».
