# P07 — отрисовка мусхафа v0

- **Агент:** GPT-A
- **Ветка:** `gpt-a/p07-mushaf-view`
- **Можно менять:** `packages/mushaf_view/`
- **ТЗ:** 2.2 (МУ-01…МУ-05, МУ-12), 11.3, 16.12, 17.5

## Что сделать

1. Виджет страницы мусхафа по разметке из P03: 15 строк, каждое слово — отдельный фрагмент текста со шрифтом своей страницы; размер шрифта подбирается под ширину.
2. Загрузка шрифтов страниц во время работы (`FontLoader`) из папки, которую передаёт приложение; окно ±3 страницы (`pageFontWindow`).
3. Состояния слова из ТЗ 11.3: обычное, скрыто, текущее, верно, возможная ошибка, ошибка, исправлено, не расслышал, открыто подсказкой. Различаются значком или начертанием, а не только цветом.
4. **Скрытое слово** рисуется прозрачным цветом, без `Opacity` (ТЗ 17.5); остальные слова не сдвигаются. В скрытом режиме видны знаки конца аята, заголовок суры и басмала (ТЗ 16.12).
5. Нажатие на слово → `WordKey` (прямоугольники через `TextPainter`, кэш на страницу и размер).
6. Каждая страница — в своей `RepaintBoundary`; смена состояния одного слова не перерисовывает остальные страницы.
7. Экранный диктор: «сура, аят» и обычный текст аята из канона (МУ-12).
8. Пока P03 не слит — работать на поддельной разметке через интерфейс.

## Готово, когда

- Виджет-тесты: нажатие на слово даёт верный `WordKey`; скрытие половины слов не сдвигает остальные.
- Пример в `example/` показывает страницы 582–583 со скрытыми словами.
- Профилирование в режиме `--profile` на телефоне — задача владельца (П-09); здесь — без пропусков кадров на эмуляторе.

## Не делать

- Не получать текст из знаков шрифта страниц: только из канона.
- Не коммитить шрифты.
