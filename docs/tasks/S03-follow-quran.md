# S03 — следование и поиск по всему Корану

- **Агент:** Opus
- **Ветка:** `opus/s03-follow-quran`
- **Можно менять:** `tools/content_build/`, `packages/quran_text/`, `packages/follow/`, `packages/testing/`, `tools/eval/`; `docs/adr/` — новый ADR; раздел 12.2 в `docs/tz/12-formaty-i-parametry.md` — по ADR 0004
- **ТЗ:** 4.8, 10.1, 10.4 (потеря позиции, поиск по Корану, неоднозначность), 2.7 (СЛ-01…), 15.5 (О-03), 15.6 (С-03)

## Зачем

Сейчас `quran_text` знает только страницы 582–583, поэтому «поиск по всему Корану» в `follow` ищет в двух страницах, и только точным совпадением троек (см. «Известные ограничения v0» в README `follow`). Одна из главных ошибок при заучивании — перескок на похожий аят в другом месте Корана. Без текста всего Корана её не поймать.

## Что сделать

1. **Текст всего Корана** из Tanzil (уже скачивается и проверяется: 114 сур, 6236 аятов) — все слова с ключами, без разметки страниц для страниц без подтверждённых прав. Как хранить слова без страницы/строки (поля пустые или отдельный текстовый пакет) и коммитить ли текст всего Корана как fixture для тестов (с атрибуцией Tanzil) — решить в **ADR 0004** и согласовать с владельцем через PR.
2. **`quran_text` по всему Корану:** ключи и индекс троек для всех слов. Замерить время построения и память на компьютере; оценить для бюджетного Android; описать, что кэшировать в `search_key_cache` / `ngram_cache` базы пользователя (таблицы делает GPT-B в O04 — здесь только интерфейс и описание).
3. **`follow`:** нечёткий поиск по всему Корану при потере позиции, а не только точное совпадение троек; кандидаты перескока вне отрывка; неоднозначность между похожими местами (СЛ-05). Пороги — только из параметров.
4. **Тесты:** перескок на похожее место в другой суре находится; повторяющиеся аяты дают неоднозначность, а не ложное открытие; чтение не из Корана не находит ничего. Места для тестов выбирать по ключам слов из базы содержания, а не набирать арабский текст.
5. **`tools/eval`:** синтетические записи с перескоками по всему Корану; показатели КЧ-01/КЧ-02 не ухудшились.

## Готово, когда

- Тесты из п. 4 проходят; переборы по суре 78 из P06 и S04 по-прежнему зелёные.
- В README `quran_text` и `follow` — замеры времени и памяти и оставшиеся ограничения.
- ADR 0004 написан; формат, анализатор, тесты всех пакетов — зелёные.

## Порядок

ADR 0004 — отдельным PR от свежего `main` сразу (только документы: `docs/adr/` и схема 12.2 в `docs/tz/12-formaty-i-parametry.md`). Код S03 — в ветке, начатой от ветки ADR; после слияния ADR — `git merge origin/main`. Изменения в `tools/eval` — после слияния №11, чтобы не было конфликтов.

## Не делать

- Не писать и не менять арабский текст; только Tanzil через `content_build`, без изменений.
- Не брать разметку страниц из источников без подтверждённых прав (ADR 0002).
- Не менять `contracts` без ADR и согласия владельца.
