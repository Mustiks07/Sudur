# E01 — экраны «Старт», «Сегодня», «Ещё»

- **Агент:** GPT-A
- **Ветка:** `gpt-a/e01-start-today-more`
- **Можно менять:** `app/`; `pubspec.lock` — как следствие
- **ТЗ:** 9 (экраны и навигация), 13 (общие состояния), 13.1 «Старт», 13.2 «Сегодня», 13.14 «Ещё», 3.4 (ПЛ-05…ПЛ-07, ПЛ-11), 3.5 (ВЗ-01), 16 (языки ru, kk, uz, en; спокойный минимализм)

## Зачем

Сейчас в приложении есть только прототип чтения. Человек должен пройти первый запуск и каждый день открывать экран «Сегодня»: что повторить, сколько это займёт, одна кнопка «Начать». Планировщик (PL01) и база (O04) уже в `main` — нужны экраны поверх них.

## Что сделать

1. **Слой данных в `app/lib/data`:** репозитории поверх `storage` (профиль, настройки, единицы, попытки, план дня) и сервис планировщика `planner`. Строки базы наружу не выходят (`AGENTS.md`).
2. **«Старт» (13.1):** язык (четыре: русский, казахский, узбекский, английский) → путь (три карточки) → знакомые суры (поиск, галочки, «Пропустить») → время (5 / 10 / 20 / своё) → модель («Скачать» / «Позже», пока — существующей загрузкой прототипа) → с чего начать → для курса «Знаете буквы?». Назад на любом шаге; прерванный старт продолжается с того же шага. Итог — профиль и единицы плана в базе.
3. **«Сегодня» (13.2):** «Сегодня — около N минут», шаги с причиной мелким текстом, одна кнопка «Начать»/«Продолжить», итог дня и «Ещё повторить». Все состояния из таблицы 13.2: первый день, перерыв ≥ 7 дней, занятие сделано, лимит бесплатной проверки, модель не загружена. Длинное нажатие — «Пропустить сегодня». План дня сохраняется (`daily_plan`) и не меняется при каждом открытии.
4. **«Ещё» (13.14):** работающие пункты — «Занятия», «Язык», «Загрузки» (модель: размер, удалить), «Мои данные» (выгрузить, загрузить, удалить всё — через `storage`), «О приложении», «Источники и лицензии». «Подписка», «Напоминания», «Помочь улучшить проверку», «Сообщить о проблеме» — заглушки «скоро».
5. **Общие состояния 13:** скелет при загрузке > 300 мс, «Нет интернета…», понятная ошибка.
6. **Тексты:** только через ARB; русские — черновики из ТЗ 13; казахские, узбекские и английские — помечены «нужен перевод» (без машинного перевода; переводят люди, ТЗ 3.1, УЧ-10).
7. **Вид:** спокойный минимализм на токенах темы из P01; полный дизайн — позже с владельцем.

- Формат, анализатор, тесты, `check_deps`, сборка Android — зелёные.
- В PR: снимки экранов и «needs owner device check».

- Не менять пакеты в `packages/` — если чего-то не хватает, написать владельцу пакета в PR.
- Не делать экран «Чтение» и подписку — это отдельные задачи.
