# P06 — следование v0

- **Агент:** Opus
- **Ветка:** `opus/p06-follow`
- **Можно менять:** `packages/follow/`, `packages/testing/` (поддельный распознаватель и наборы результатов распознавания)
- **ТЗ:** 2.7 (СЛ-01…СЛ-08), 10.4, 12.4 (параметры следования), 14.2

## Что сделать

1. Вход — поток `RecognitionResult`, слова диапазона с ключами (P02), параметры. Выход — `PositionUpdate`, `WordRevealed`, `PositionLost` и путь выравнивания для будущего `check`.
2. Устойчивая часть частичных результатов (СЛ-08).
3. Выравнивание лучом (ТЗ 10.4): совпадение, пропуск до `maxSkip`, возврат до `maxBack`, лишнее слово; стоимости и пороги — параметры, без чисел в коде.
4. Правила открытия слова (10.4): порог `openThreshold` и одинаковость пути у гипотез луча.
5. Потеря позиции: поиск в отрывке; поиск по Корану — через интерфейс `quran_text` (для v0 достаточно суры 78).
6. Неоднозначность (СЛ-05): несколько кандидатов, `confidence: low`.
7. В `packages/testing/`: поддельный распознаватель, проигрывающий заранее подготовленные результаты. Результаты для тестов строятся **из канона** суры 78 (ключи слов, пропуски, повторы, искажения букв), а не из выдуманного арабского текста.

## Готово, когда

Автотесты из ТЗ 14.2 для `follow` проходят: чистое чтение, начало с середины, повтор, пропуск, длинная пауза, меняющиеся частичные результаты (без «отменённых» открытий).

## Не делать

- Не решать, правильно ли прочитано: это `check` (волна 2).
- Не подставлять ожидаемый текст вместо распознанного.
