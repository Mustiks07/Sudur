# P03 — данные суры 78 для прототипа

- **Агент:** Opus
- **Ветка:** `opus/p03-content-build`
- **Можно менять:** `tools/content_build/`, `packages/testing/` (только папка `fixtures/`)
- **ТЗ:** 4.8 (база содержания), 4.9, 6.1, 12.2, ПР-02, ПР-04

## Что сделать

1. Скрипт `tools/content_build`, который **скачивает** исходные данные в `third_party_cache/` (папка в `.gitignore`):
   - канонический текст Uthmani из Tanzil (без изменений, с сохранением атрибуции);
   - разметку страниц мединского мусхафа 15 строк и слова с позициями из QUL;
   - шрифты страниц QPC V2 для страниц 582–583.
2. Сборка для суры 78:
   - таблицы `surah`, `ayah`, `word`, `page`, `line` по схеме ТЗ 12.2 (`word_index`, `text_uthmani`, `page`, `line`, `line_position`, `glyph_code`);
   - результат — файл базы SQLite и JSON-копия для тестов.
3. Проверки (ПР-04): число аятов и слов суры совпадает с источником; контрольная сумма канона; каждое слово имеет страницу, строку и знак шрифта.
4. Файл `ATTRIBUTION.md` с источниками и лицензиями; у результата — идентификатор лицензии (ПР-02).
5. Небольшая тестовая копия данных суры 78 (текст, слова, разметка, без шрифтов) — в `packages/testing/fixtures/` с атрибуцией Tanzil. Текст Tanzil можно распространять без изменений со ссылкой на источник (ТЗ 6.1).

## Готово, когда

- Одна команда собирает данные суры 78 с нуля.
- Проверки ПР-04 проходят; тесты на них есть.
- В репозитории нет шрифтов и сырых скачанных файлов.

## Не делать

- Не набирать, не исправлять и не «нормализовать» арабский текст вручную или языковой моделью: только скачанный канон без изменений.
- Не коммитить шрифты.
