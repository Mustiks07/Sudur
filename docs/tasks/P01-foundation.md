# P01 — каркас приложения и зелёный CI

- **Агент:** GPT-A
- **Ветка:** `gpt-a/p01-foundation`
- **Можно менять:** `app/`, корневые `pubspec.yaml`, `analysis_options.yaml`, `.github/workflows/`, `.fvmrc`, `tools/check_deps.sh`, раздел «Commands» в `AGENTS.md`; исправления формата и предупреждений анализатора в любых файлах каркаса без изменения смысла
- **ТЗ:** 4.1, 4.2, 4.7, 8.1, 8.2, 8.6, 8.7, 17.1, 17.2

## Что сделать

1. Закрепить последнюю стабильную версию Flutter через FVM (`.fvmrc`); CI берёт ту же версию.
2. Закрепить точные версии `very_good_analysis`, `meta`, `test` вместо `any`.
3. `flutter create --org kz.sudur --project-name sudur --platforms android,ios app`; добавить `app` в `workspace` корневого `pubspec.yaml`; `resolution: workspace` в `app/pubspec.yaml`.
4. Каркас по официальному руководству Flutter (ТЗ 17.1):
   - `app/lib/ui/core/` — тема на токенах (цвета, шрифты, отступы, скругления; светлая и тёмная), общие элементы;
   - `app/lib/routing/` — go_router;
   - `app/lib/config/` — сборка зависимостей через `provider`;
   - `app/lib/data/repositories/`, `app/lib/ui/<функция>/{views,view_models}/` — пустые заготовки с README;
   - точки входа для вариантов `dev`, `beta`, `prod` (ТЗ 8.7).
5. Локализация ARB: `ru`, `kk`, `uz`, `en`, несколько строк-примеров; строка по умолчанию — язык системы, если он из списка.
6. Пустой главный экран «Sudur» с нижним меню из ТЗ 9.1 (пункты-заглушки).
7. `tools/check_deps.sh`: проверяет правила зависимостей из ТЗ 4.2 (пакеты на чистом Dart не импортируют Flutter; никто не импортирует чужой `src/`; только `app` зависит от сервисов) и падает при нарушении.
8. Привести весь каркас к зелёному CI: `dart format`, `flutter analyze` без предупреждений, тесты `contracts` проходят.
9. Обновить раздел «Commands» в `AGENTS.md` под реальные команды.

## Готово, когда

- CI зелёный на запросе на слияние.
- `fvm flutter run` запускает приложение на Android-эмуляторе с пустым главным экраном и нижним меню на 4 языках.
- Правила зависимостей проверяются в CI.

## Не делать

- Не добавлять логику функций: только каркас.
- Не менять смысл `packages/contracts` (только формат и предупреждения анализатора).
