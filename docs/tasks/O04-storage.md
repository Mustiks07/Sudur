# O04 — база пользователя

- **Агент:** GPT-B
- **Ветка:** `gpt-b/o04-storage`
- **Можно менять:** `packages/storage/`; `pubspec.lock` — как следствие новых зависимостей
- **ТЗ:** 4.8 (ДН-01…ДН-04), 11.5, 12.1, 5.2 (НФ-21), 17 (правила кода)

## Зачем

Прогресс человека — план, попытки, ошибки, сессии, настройки — хранится на телефоне в базе пользователя. От неё зависят план повторений, экран «Сегодня», разбор ошибок и синхронизация.

## Что сделать

1. **Схема drift** строго по ТЗ 12.1: все таблицы, поля, ключи и индексы; версия схемы 1; `outbox` создаётся пустой. Время — миллисекунды UTC, идентификаторы — UUID v4.
2. **Открытие базы в фоновом изоляте** (drift). Путь к файлу передаётся снаружи; в тестах — база в памяти.
3. **Репозитории из ТЗ 11.5:** `UnitRepository`, `AttemptRepository`, `CheckEventRepository`, `SessionRepository`, `LessonRepository`, `SettingsRepository`, `DownloadRepository`, `RecordingRepository`, `UploadQueueRepository`, плюс доступ к `daily_plan`, `free_usage`, `entitlement_cache`, `search_key_cache`, `ngram_cache`. Абстрактный класс + реализация на drift; ошибки — через `Result`; модели неизменяемые; JSON-поля (`hints`, `error_event_ids`, `versions`, `summary`, `items`, `meta`) — типизированные, с проверкой при чтении.
4. **Запись после каждого отрывка (НФ-21):** попытка, её события проверки и новое состояние единицы пишутся одной транзакцией. Тест: сбой посреди транзакции не оставляет половину данных.
5. **Миграции (ДН-01):** снимки схемы drift (`drift_dev schema dump`), тест миграции со всех прежних версий; для версии 1 — базовый тест и описанный в README порядок для следующих версий.
6. **Выгрузка и загрузка (ДН-02):** все таблицы в JSON внутри zip-архива с версией схемы; загрузка проверяет архив (zip-slip, версия, формат) и заменяет данные целиком или не меняет ничего.
7. **Полное удаление (ДН-04):** база пустеет, файлы сохранённых записей из `saved_recording` удаляются (файловая система передаётся снаружи, чтобы проверить в тестах).
8. **Резервная копия (ДН-03):** правила резервного копирования Android и iOS живут в `app/` — их не трогать; в README описать, что приложению нужно включить (база — в копию, записи голоса — нет).
9. Сгенерированный код drift коммитится; формат и анализатор зелёные (для `*.g.dart` можно добавить исключение в `packages/storage/analysis_options.yaml`, подключив корневые правила).

## Готово, когда

- Тесты каждого репозитория на базе в памяти, тест транзакции из п. 4, тест миграции, тест «выгрузка → удаление → загрузка восстанавливает всё», тест полного удаления.
- Формат, анализатор, тесты, `check_deps` — зелёные; новые зависимости с лицензией и одной строкой обоснования в описании PR.

## Не делать

- Не хранить звук в базе; не писать распознанный текст и звук в журналы.
- Не менять `contracts` и `app/`. Если для репозиториев нужны общие типы в `contracts` — черновик ADR в описании PR, решают Астра и владелец.
