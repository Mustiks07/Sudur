# 0002. Ответы на вопросы волны 1

- Статус: принято
- Дата: 16.11.2026
- Кто принял: владелец (по предложению из отчёта Opus по P03, P02, P06)

## Контекст

Opus закончил P03, P02, P06 (запросы на слияние №1–3) и поднял вопросы, которые решает не он.

## Решения

| Вопрос | Решение |
|---|---|
| Разметка страниц берётся из открытого API Quran.com, а не из файла QUL (там нужен вход) | Для прототипа — да. По условиям Quran Foundation коммерческое использование сырых данных требует отдельного договора, поэтому до выпуска: файл QUL (владелец скачает) или договор. Запись в реестре прав (ТЗ 6.1) — «только прототип» |
| Права на разметку и шрифты не подтверждены | Только прототип; задача Э0-07 остаётся |
| Отличия от схемы базы содержания (ТЗ 12.2): поля места и знака конца аята, номер суры у строк заголовка | Принять, внести в ТЗ 12.2 |
| Названия сур на русском, казахском, узбекском пусты | Принять: заполнить из источника с правами позже |
| `similar_pair`, `passage_default`, `tajweed_mark` в v0 не собираются | Принять: волна 2 |
| Новые параметры следования `openDelayWords` = 2, `lostWindowWords` = 4 | Принять, внести в ТЗ 12.4 |
| Порядок слияния: №1 → №2 → №3 (P02 построен на P03, P06 на P02) | Принять |
| `pubspec.lock` | Хранить в репозитории один корневой `pubspec.lock` рабочей области: это приложение, версии должны быть закреплены (ТЗ 8.11). Добавляет задача P01 |
| Правило замены ٱ → ا и похожие | Только из `normalizer.json` пакета модели (P04), не в коде |

## Последствия

- До выпуска нужна разметка с подтверждёнными правами.
- Пороги следования подстраиваются на записях владельца (М-04).
