# 11. Модули обучения, мусхафа и данных: подробная спецификация

Пакеты `planner`, `lessons`, `mushaf_view`, `content`, `storage`, `entitlements`, отправка записей и уведомления.

## 11.1 `planner` — план и занятие на сегодня

### Жизнь единицы плана

```
отрывок:  notStarted → learning → recent → old
                          ↑                  │
                          └── (ошибка «Забыл» в old дважды подряд) — переучивание
трудное место: open → practicing → closed (два чистых чтения с интервалом ≥ 1 день)
навык:    learning → review (по FSRS)
```

- `learning` → `recent`: одно чистое чтение в режиме «Проверяю себя» (ЗН-02).
- `recent` → `old`: прошло `recentDays` = 30 дней с перехода в `recent` и последние 2 попытки — «Хорошо» или «Легко».
- Каждая оценённая попытка обновляет карточку FSRS (пакет `fsrs`), даже в `recent`: так при переходе в `old` у единицы уже есть история.

### Сроки

| Очередь | Когда положено повторить |
|---|---|
| `learning` | Каждое занятие, пока не выучено |
| `recent` | По лестнице `recentLadderDays` = [1, 2, 4, 7, 7, 7…] от последней попытки |
| `old` | Срок карточки FSRS при целевой вероятности `desiredRetention` = 0,9 |
| Трудное место | Через 1 день, затем 3 дня |
| Навык курса | Срок карточки FSRS |

### Оценка времени

- Личная скорость `speed` — секунд на слово; скользящее среднее последних 10 попыток в режиме вспоминания; до истории — `defaultSecondsPerWord` = 1,0.
- Стоимость шага = слова × `speed` × множитель режима:

| Шаг | Множитель |
|---|---|
| Проверка себя или вспоминание выученного | 1,3 |
| Трудное место (упражнение) | 3,0 |
| Заучивание нового (все шаги ЗН-01) | 8,0 |
| Урок курса | Длительность урока из пакета |

### Сборка занятия на сегодня

```
вход: бюджет B (секунды), сегодняшняя дата, состояния единиц
0. если перерыв ≥ breakDays (7) и диагностика не пройдена → занятие = диагностика (11.1, ниже)
1. вчерашний новый отрывок (если был)                      → добавить
2. трудные места со сроком ≤ сегодня, по сроку              → добавлять, пока сумма ≤ 0,25 × B
3. recent со сроком ≤ сегодня, по сроку                     → добавлять
4. old со сроком ≤ сегодня, по возрастанию вероятности вспомнить → добавлять
   шаги 3–4 останавливаются, когда сумма ≥ (1 − newShare) × B, newShare = 0,2
5. долг = стоимость повторений со сроком ≤ сегодня, не попавших в занятие
   если остаток ≥ 0,2 × B и долг ≤ debtLimit (= B) → новый отрывок, начатый или следующий
6. путь «Учусь читать» активен → урок + навыки со сроком (по стоимости, в пределах B)
7. у каждого шага — причина (ПЛ-05)
выход: список шагов, оценка «около N минут» (округление до минуты)
```

Если всё помещается — занятие короче бюджета, это нормально. Дополнительно можно «Ещё повторить» — следующие по сроку единицы.

### Диагностика после перерыва (ВЗ-02)

- Выборка из `old` и `recent`: 3–5 отрывков (`diagnosticSize`), с весом за давность и прежние ошибки, из разных сур.
- Режим — «Проверяю себя».
- После диагностики первые 7 дней `newShare` уменьшается вдвое (ВЗ-04).

### Восстановление (ВЗ-05)

- Отмеченные суры получают единицы в состоянии `notStarted` с пометкой «знал раньше».
- Первая проверка каждой суры — «Проверяю себя» по 2–3 случайным отрывкам.
- Чисто → отрывки сразу в `recent`; с ошибками → ускоренное закрепление: шаги ЗН-01 без прослушивания трижды, сразу «вспомнить».

### Состояние карты памяти (КП-01) выводится из данных

| Состояние | Условие |
|---|---|
| Ознакомился | Только прослушивание или чтение с поддержкой |
| С помощью | Последняя попытка — с подсказками |
| Самостоятельно | Последняя попытка чистая, интервал ещё не проходил |
| Подтвердил позже | Две чистые попытки с интервалом ≥ 1 день |
| Давно не проверял | Срок прошёл больше чем на 7 дней или вероятность вспомнить < 0,7 |
| Есть трудное место | Есть открытое трудное место |

## 11.2 `lessons` — движок уроков

### Состояния урока

```
locked → available → inProgress(шаг) → quiz → passed
                                            ↘ failed → inProgress (трудные шаги)
```

Урок открывается, когда пройден предыдущий урок этапа или входное упражнение (СТ-05) поставило старт дальше.

### Типы шагов и данные

| Тип (`type`) | Поля | Результат |
|---|---|---|
| `explain` | `text`, `image?`, `audio?` | Просмотрено |
| `listen` | `audio`, `highlight` (что подсвечивать) | Прослушано |
| `repeatAndCompare` | `audio` | Самооценка: получилось / не совсем |
| `hearAndChoose` | `audio`, `options[]`, `answer` | Верно / неверно |
| `seeAndChoose` | `prompt` (буква, слог), `optionsAudio[]`, `answer` | Верно / неверно |
| `pairDiscriminate` | `audio`, `pair[2]`, `answer` | Верно / неверно |
| `findForm` | `letter`, `position` (начало, середина, конец, отдельно), `options[]`, `answer` | Верно / неверно |
| `buildSyllable` | `target`, `pieces[]` | Верно / неверно |
| `readSupported` | `range` (слова Корана) | Сессия чтения в режиме с поддержкой |
| `findRule` | `range`, `rule`, `answerWords[]` | Доля найденных |
| `quiz` | `stepIds[]`, `passPercent` | Процент |

Все тексты шагов — на трёх языках (УЧ-10).

### Навыки

- Каждый урок перечисляет `skills` (например, `letter:ba`, `haraka:kasra`, `rule:ikhfa`).
- После прохождения урока навыки становятся единицами плана.
- Повторение навыка — 3 вопроса типов `hearAndChoose`, `seeAndChoose`, `pairDiscriminate`, `findRule`, помеченных этим навыком; оценка FSRS: все верно — «Хорошо», одна ошибка — «Трудно», больше — «Забыл».

## 11.3 `mushaf_view` — отрисовка страниц

### Отрисовка

- Страница = 15 строк из разметки; каждая строка — один `TextPainter` со шрифтом страницы, каждое слово — отдельный фрагмент текста со своим стилем.
- Размер шрифта подбирается так, чтобы самая широкая строка занимала ширину страницы; одинаков для всех строк страницы.
- Скрытое слово рисуется прозрачным (размеры сохраняются), поэтому остальные слова не сдвигаются. Знаки конца аята, заголовки сур и басмала видны всегда; линия на месте слова — только если включена в настройках (МУ-04, раздел 16.12).
- Прямоугольники слов — из `TextPainter.getBoxesForSelection` по диапазону слова; кэш на страницу и размер экрана.
- Нажатие → поиск прямоугольника → `WordKey` (МУ-03).

### Состояния слова и вид

| Состояние | Вид [Р, уточняется в макетах] |
|---|---|
| Обычное | Цвет текста |
| Скрыто | Прозрачно (линия — по настройке) |
| Текущее | Мягкая подложка |
| Верно | Цвет текста |
| Возможная ошибка | Цвет внимания + точка под словом |
| Ошибка | Цвет ошибки + подчёркивание |
| Исправлено | Цвет текста + маленькая галочка |
| Не расслышал | Приглушённый цвет + знак вопроса |
| Открыто подсказкой | Цвет текста + значок подсказки |

### Шрифты

- Окно загрузки: текущая страница ±3 (`pageFontWindow`), загрузка в паузах между кадрами (`FontLoader`).
- Если шрифт страницы не успел загрузиться — показывается заглушка «загрузка» не дольше 300 мс (НФ-18), затем страница.

### Доступность (МУ-12)

Для экранного диктора — смысловая разметка по аятам: «Сура N, аят M» и обычный арабский текст аята из канона.

## 11.4 `content` — пакеты и загрузки

### Состояния пакета

```
notInstalled → queued → downloading(%) → verifying → installing → installed
                                    ↘ failed(причина) → queued (повтор)
installed → updateAvailable → (тот же путь для новой версии)
```

### Установка целиком или никак (ДФ-05)

1. Загрузка в `packages/<id>/<version>.tmp/`.
2. Проверка SHA-256 и подписи манифеста.
3. Распаковка, переименование в `packages/<id>/<version>/`.
4. В базе пользователя `download.active_version` = новая версия — одной транзакцией.
5. Старая версия удаляется после следующего успешного запуска.

### Проверка манифеста

- Раз в сутки при наличии сети и при открытии «Загрузки».
- Манифест подписан Ed25519; в приложении два открытых ключа: основной и запасной (раздел 8.10).
- Пакет с `minAppVersion` выше текущей не ставится; пользователю — «Обновите приложение».

## 11.5 `storage` — база пользователя

- drift, отдельный фоновый изолят.
- Репозитории по сущностям: `UnitRepository`, `AttemptRepository`, `CheckEventRepository`, `SessionRepository`, `LessonRepository`, `SettingsRepository`, `DownloadRepository`, `RecordingRepository`, `UploadQueueRepository`.
- Запись попыток — после каждого отрывка (НФ-21).
- Схема — раздел 12.1.

## 11.6 `entitlements` — подписка

### Продукты [Р]

| Идентификатор | Что | Цена [Г] |
|---|---|---|
| `premium_monthly` | Подписка на месяц, пробный период 7 дней | 1000 тенге |
| `premium_yearly` | Подписка на год | около 10 000 тенге |

Право доступа одно — `premium`.

### Состояния доступа

| Состояние | Что доступно |
|---|---|
| `free` | Бесплатная часть (раздел 6.4) |
| `trial` | Всё |
| `active` | Всё |
| `grace` | Всё; магазин не смог списать оплату, ждём |
| `expiredOffline` | Всё ещё `offlineGraceDays` = 14 дней после окончания, если не было сети |
| `expired` | Бесплатная часть |

### Лимит бесплатной проверки (ПК-05)

- Считается время в состоянии `listening` для режимов «Пробую вспомнить» и «Проверяю себя».
- Лимит `freeVoiceMinutesPerDay` = 10; сброс в полночь по времени телефона.
- Когда лимит исчерпан посреди отрывка — отрывок дочитывается до конца, затем предложение подписки или самопроверки.

## 11.7 Отправка записей (СБ)

### На телефоне

- При согласии (СБ-01) после каждой сессии создаётся пакет: звук отрывка в Opus 16 кбит/с + JSON с метаданными (раздел 12.5).
- Очередь — `upload_queue` в базе; размер файлов ≤ `uploadQueueMaxMb` = 200.
- Отправка фоном при Wi-Fi (или любой сети, если разрешено), спорные места первыми (СБ-04).

### Сервер

| Запрос | Что делает |
|---|---|
| `POST /v1/uploads` | Тело: идентификатор установки, размер, SHA-256, версия согласия; запрос подписан ключом установки. Ответ: одноразовая ссылка на загрузку на 15 минут |
| `PUT <ссылка>` | Загрузка файла прямо в хранилище |
| `POST /v1/uploads/{id}/complete` | Подтверждение; сервер проверяет сумму |
| `POST /v1/erase` | Удаление всех записей установки; подписан тем же ключом |

- Ключ установки (Ed25519) создаётся на телефоне при согласии; сервер хранит только открытый ключ — так удалить данные может только этот телефон (СБ-06).
- Ограничение частоты: не больше 200 загрузок в сутки с одной установки.
- Срок хранения записей — по заключению юриста (ЮР-01); до него — не больше 24 месяцев [Г].

## 11.8 Уведомления (НП)

- Локальные, без сервера (flutter_local_notifications).
- Расписание: выбранные человеком привычки («после фаджра» и т. п.) с временем, заданным вручную; не больше `maxRemindersPerDay` = 2.
- Если занятие на сегодня уже сделано — напоминание этого дня не приходит.
- Текст нейтральный: «Время для занятия — около 10 минут».
