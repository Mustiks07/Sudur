## 5.3 Качество следования и проверки

### Определения

- **Точность (precision)** подтверждённых ошибок — доля настоящих ошибок среди всех ошибок, которые приложение подтвердило.
- **Полнота (recall)** — доля найденных среди всех настоящих ошибок.
- **Ложная тревога** — подтверждённая ошибка там, где человек прочитал правильно.
- **Отказ** — «не удалось проверить».

Пример расчёта Астры: при 2% ошибок в чтении, полноте 90% и ложных тревогах на 1% правильных слов точность всего 64,7%. Поэтому порог ложных тревог жёсткий.

### Пороги [Г — утверждаются владельцем после пилота]

| ID | Показатель | Порог |
|---|---|---|
| КЧ-01 | Следование: слова открыты на своих местах при правильном чтении | ≥ 98% |
| КЧ-02 | Следование: открыто слово, которого не было в чтении | ≤ 1% |
| КЧ-03 | Точность подтверждённых ошибок | ≥ 95% |
| КЧ-04 | Полнота пропусков; полнота замен — отдельно | ≥ 85% каждая |
| КЧ-05 | Ложные тревоги | ≤ 1 на 1000 правильно прочитанных слов |
| КЧ-06 | Отказы на записях нормального качества | ≤ 10% слов |
| КЧ-07 | Самоисправления распознаны как исправления | ≥ 90% |
| КЧ-08 | Точность в каждой группе (родной язык русский, казахский, узбекский; мужчины и женщины; класс телефона; тишина и шум) | ≥ 90%, отчёт по каждой группе |
| КЧ-09 | Доверительные интервалы считаются бутстрепом по людям, а не по словам | — |

### Режим выпуска по результату [Р]

| Результат | Что выпускаем |
|---|---|
| **А.** Все пороги пройдены | Проверка на ходу, мягкое и строгое поведение |
| **Б.** Точность и ложные тревоги в норме, полнота ниже | Проверка после фразы, пометка «бета», без строгого поведения |
| **В.** Точность или ложные тревоги не в норме | Только следование и самопроверка; приложение не объявляет ошибки, а предлагает «проверьте это место сами» без влияния на план |
| **Г.** Не прошло и следование (КЧ-01, КЧ-02) | Чтение с поддержкой по видимому тексту и самопроверка; продолжаем работу над моделью |

**Решение владельца (раздел 16.10):** публичный выпуск — только в режиме А. Режимы Б–Г допустимы лишь в закрытом тесте; пока пороги не пройдены, продолжается работа над моделью.

## 5.5 Набор записей

**Объём [Г — по оценке Астры, не статистический расчёт]:**

- **Пилот:** 30–50 взрослых, 10–20 часов, минимум по 10 человек с родным русским, казахским, узбекским; разные телефоны, пол, тишина и шум.
- **Закрытый тестовый набор:** 90–150 новых людей, 30–50 часов; не пересекается с пилотом по людям.
- **Диагностический набор:** намеренные пропуски, замены, перескоки; отдельно от естественного чтения.
- **Новички:** медленное чтение по слогам — для И-4.

**Разметка:** дословно прочитанные слова, ожидаемый отрывок, время слов, повторы, самоисправления, подсказки, остановки, неразборчивые места, шум. Два разметчика для тестового набора, третий решает разногласия.

**Разделение** на обучение, настройку и тест — только по людям. Дубликаты ищутся по звуку, а не по именам файлов.

**Согласие:** отдельно на участие, хранение для исследования, обучение модели, публикацию. Только взрослые. Раздел 6.

**Набор против ухудшения качества [Р]:** результаты распознавания эталонных записей сохранены в файлах (JSON) вместе с разметкой. Инструмент `tools/eval` прогоняет следование и проверку на компьютере при каждом изменении пакетов `follow`, `check`, `quran_text`. Изменение не принимается, если точность упала больше чем на 1 процентный пункт или полнота — больше чем на 2.

## 5.7 Метрики продукта

В V1 нет сервера и нет аналитики [Р]. Метрики собираются в закрытом тесте: по согласию человек отправляет файл диагностики без записей голоса, плюс интервью.

| Метрика | Зачем |
|---|---|
| Завершено ли первое занятие | Понятен ли старт |
| Вернулся ли на 7-й день | Удержание |
| Доля законченных занятий на сегодня | Посильность плана |
| Доля «Не согласен» и «не удалось проверить» | Доверие к проверке |
| Воспроизведение без подсказки через неделю — оценка независимым преподавателем на части участников | Учит ли приложение, а не только проверяет |
| Время до закрепления отрывка | Эффективность |

Оценивать обучение только той же моделью, которая учит, нельзя.
