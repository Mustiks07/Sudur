# 14. План тестирования

Дополняет раздел 5: что именно проверяется, какими случаями и в каком порядке.

## 14.1 Уровни

| Уровень | Где | Когда | Кто |
|---|---|---|---|
| Автотесты пакетов | Компьютер, CI | Каждое изменение | Агенты пишут, CI запускает |
| Снимки экранов | CI | Изменение мусхафа и экранов | CI |
| Прогон набора записей | Компьютер, CI | Изменение `follow`, `check`, `quran_text`; новая модель | CI |
| Сценарии на телефонах | Эталонные телефоны | Конец каждого этапа, перед выпуском | Владелец |
| Замеры скорости | Эталонные телефоны, Мак для iOS | Прототип, перед выпуском, новая модель | Владелец |
| Закрытый тест | Люди | Этап 7 | 50–200 человек |

## 14.2 Обязательные случаи автотестов

### `quran_text`

- Канон: 114 сур, 6236 аятов, число слов совпадает с источником.
- Нормализатор: каждое правило таблицы на примерах; канон после нормализации не изменился.
- Поиск последовательности находит аят по 3 словам из его середины.

### `follow` (на сохранённых результатах распознавания)

| Случай | Ожидается |
|---|---|
| Чистое чтение отрывка | Все слова открыты по порядку |
| Начало с 5-го аята | Открытие с 5-го аята |
| Повтор предыдущих 3 слов | Позиция вернулась, лишних открытий нет |
| Пропуск одного слова | Следующие слова открыты; пропущенное — нет (до решения `check`) |
| Сура 55, повторяющийся аят | Неоднозначность до различающего слова |
| Переход на аят другой суры | Кандидат перескока, слова вне отрывка не открыты |
| Частичные результаты меняются | Ни одно слово не открыто и затем «отменено» |
| Длинная пауза посреди аята | Позиция сохраняется |

### `check`

| Случай | Ожидается |
|---|---|
| Пропуск, затем 2 верных слова | `omission` → `confirmed` |
| Пропуск, затем конец сессии | `omission` → `unverified` |
| Другое слово (сходство < 0,6), затем 2 верных | `substitution` → `confirmed` |
| Похожее слово (0,6–0,85) | `unverified` |
| Ошибка и исправление в течение 2,5 с | `corrected` |
| Плохой звук на слове | `unverified` |
| 3 слова другого аята подряд | `jump` → `confirmed` |
| Возврат на 2 слова назад | Повтор, не ошибка |
| Строгое поведение | Слова после ошибки не открываются до правильного |
| «Не согласен» | `disputed`, оценка в плане не ставится |
| Распознанный текст в событии | Всегда сырой, не канон |

### `planner`

| Случай | Ожидается |
|---|---|
| Бюджет 5 минут, большой долг | Нового нет, причина показана |
| Бюджет 20 минут, долга нет | Новое есть, доли около 20/30/50 |
| Перерыв 10 дней | Занятие — диагностика |
| Отрывок: чистая «Проверка себя» | `learning` → `recent` |
| 30 дней в `recent`, 2 попытки «Хорошо» | → `old` |
| Каждая строка таблицы оценок (3.4) | Нужная оценка FSRS |
| Сессия на 2,5 отрывка | 2 попытки (ПЛ-12) |
| Самопроверка «Вспомнил» | «Хорошо», не «Легко» |

### Остальные пакеты

- `lessons`: каждый тип шага; мини-проверка 79% и 80%; навыки создаются после урока.
- `content`: обрыв загрузки, неверная сумма, неверная подпись, `minAppVersion` выше текущей — текущая версия не ломается.
- `storage`: миграции со всех прежних версий схемы; выгрузка → удаление → загрузка.
- `entitlements`: все переходы состояний; лимит 10 минут и сброс в полночь; 14 дней без сети.
- Отправка записей: без согласия — ни одного запроса; офлайн → Wi-Fi → очередь пуста; переполнение очереди.

## 14.3 Сценарии на телефонах

Каждый — на 2 Android (дешёвый и средний) и 1 iPhone. Отметка: прошёл / не прошёл / замечание.

| № | Сценарий | Что проверить |
|---|---|---|
| ТС-01 | Первый запуск, путь «Учу наизусть», без сети после установки | Мусхаф и первые уроки работают |
| ТС-02 | Первый запуск, путь «Учусь читать», входное упражнение | Старт с нужного урока |
| ТС-03 | Загрузка модели, обрыв Wi-Fi посередине | Продолжение загрузки |
| ТС-04 | Занятие на сегодня целиком | Время примерно совпадает с оценкой |
| ТС-05 | Чтение со скрытым текстом, чисто | Слова появляются, итог «чисто» |
| ТС-06 | Чтение с намеренным пропуском и заменой | Обе ошибки найдены, разбор работает |
| ТС-07 | Самоисправление | «Исправлено», а не ошибка |
| ТС-08 | Звонок посреди чтения | Пауза, продолжение без потерь |
| ТС-09 | Bluetooth-наушники | Предупреждение о качестве |
| ТС-10 | Отказ в доступе к микрофону | Самопроверка, путь к настройкам |
| ТС-11 | Строгое поведение | Ожидание правильного слова, подсказка через 15 с |
| ТС-12 | «Не согласен» | Нет штрафа в плане |
| ТС-13 | Лимит бесплатной проверки | Отрывок дочитан, предложение подписки |
| ТС-14 | Покупка в тестовом режиме магазина, отмена, восстановление | Доступ появляется и пропадает правильно |
| ТС-15 | Перевод часов на неделю вперёд | Режим возвращения |
| ТС-16 | Урок с «Повтори и сравни» | Запись удалена после шага |
| ТС-17 | Смена языка | Все экраны на новом языке |
| ТС-18 | Масштаб шрифта 200%, TalkBack и VoiceOver | Экраны не ломаются, диктор читает |
| ТС-19 | Согласие на отправку записей, офлайн-сессия, затем Wi-Fi | Записи отправлены |
| ТС-20 | Выгрузка, переустановка, загрузка данных | Прогресс восстановлен |

## 14.4 Замеры скорости

1. Тестовый режим сборки `dev`: подача эталонной записи в сессию в реальном темпе, в обход микрофона; журнал времени событий.
2. Задержка появления слова = время `WordRevealed` − конец слова по разметке (НФ-10).
3. Задержка решения = время `confirmed` − время, когда прозвучало `confirmContextWords` слов после ошибки (НФ-11).
4. 20 минут непрерывно: скорость обработки, память (Android Profiler, Xcode Instruments на Маке), температура (НФ-12…НФ-15).
5. Батарея: тот же 20-минутный сценарий без распознавания и с ним, яркость 50%, режим полёта.
6. Каждый замер — 3 повтора, в отчёт — p50 и p95.
