# 3. Обучение, упражнения и план

## 3.1 Путь «Учусь читать» (УЧ)

Курс от первых букв до чтения коротких сур, затем переход к заучиванию. ТЗ задаёт движок, формат и минимальный объём.

**Кто делает содержание [Р]:** черновики уроков готовит владелец; тексты объяснений можно набросать с помощью ИИ. Проверяет и утверждает специалист по чтению Корана — это разовая работа, а не постоянный учитель в приложении. Звуки букв и слогов записывает человек с правильным произношением; синтез речи не используется. Арабский текст берётся только из канонической базы.

### Этапы курса

**Решение владельца:** курс строится по порядку «Муаллим сани» — актуальная таблица этапов в разделе 16.9; таблица ниже — прежняя рамка, оставлена для истории.

Последовательность близка к традиционным букварям: «Нурания каида» и «Муаллим сани» (по нашим сведениям, распространён в мечетях региона; не проверено). Ориентир — 40–60 уроков по 5–10 минут [Г].

| Этап | Что изучается | Голос в V1 |
|---|---|---|
| 1. Буквы | 28 букв по звуку; похожие по форме (ب ت ث); похожие по звуку (س ص, ت ط, د ض, ذ ز ظ, ه ح, ء ع, ك ق) | Повтори и сравни на слух |
| 2. Формы букв | Начало, середина, конец слова, отдельно; буквы, которые не соединяются слева (ا د ذ ر ز و) | — |
| 3. Короткие огласовки | Фатха, касра, дамма; открытые слоги | Повтори и сравни на слух |
| 4. Танвин | Три вида танвина | То же |
| 5. Долгие гласные | Естественный мадд: ا و ي; малые алиф, вав, йа | То же |
| 6. Сукун | Закрытые слоги | То же |
| 7. Шадда | Удвоение; шадда с огласовками и танвином | То же |
| 8. Чтение слов и фраз из Корана | Лунные и солнечные буквы, соединительный алиф, знаки остановки | «Читаю с поддержкой» — подсветка вслед за голосом |
| 9. Основы таджвида | Раздел 3.2 | Повтори и сравни на слух |
| 10. Короткие суры | Аль-Фатиха, суры 112–114 и далее по выбору преподавателя | «Читаю с поддержкой», затем переход к заучиванию с полной проверкой слов |

**Проверка голосом в первых этапах.** Основная модель выдаёт буквы без огласовок: «ба», «би» и «бу» для неё одинаковы. Поэтому для уроков нужна отдельная фонемная модель. По решению владельца она входит в V1, если пройдёт испытание И-5 (раздел 16.9). Сравнение на слух — образец, своя запись, самооценка — есть всегда.

### Движок уроков

Урок — последовательность шагов. Типы шагов:

| Тип шага | Что делает человек | Очередь |
|---|---|---|
| Объяснение | Читает короткий текст с картинкой, слушает звук | V1 |
| Прослушай | Слушает образец, буква или слово подсвечивается | V1 |
| Повтори и сравни | Слушает → записывает себя → слушает оба → оценивает сам: «получилось / не совсем» | V1 |
| Узнай на слух | Слышит звук → выбирает букву или слог из 3–4 | V1 |
| Узнай на вид | Видит букву или слог → выбирает звук из 3–4 | V1 |
| Различи пару | Похожие буквы: какая звучит | V1 |
| Найди форму | Выбирает форму буквы для позиции в слове | V1 |
| Собери слог или слово | Перетаскивает буквы и огласовки | V1 |
| Прочитай с поддержкой | Читает вслух, слова подсвечиваются вслед за голосом (только для текста из Корана) | V1 |

## 3.4 План и занятие на сегодня (ПЛ)

### Единицы плана [Р]

| Единица | Что это | Когда создаётся |
|---|---|---|
| Отрывок | Диапазон слов: 1–5 аятов, не больше половины страницы (параметр); длинный аят — отдельная единица | При добавлении суры в заучивание или отметке знакомой |
| Стык | Конец одного отрывка и начало следующего | После ошибки на переходе |
| Трудное место | Несколько слов вокруг подтверждённой ошибки | После подтверждённой ошибки; закрывается после двух чистых чтений с интервалом |
| Навык | Буква, огласовка, правило таджвида | После урока курса |

### Очереди

- **Новое** — в работе, ещё не прочитано самостоятельно.
- **Недавнее** — прочитано самостоятельно меньше 30 дней назад (параметр); повторяется по фиксированной лестнице 1–2–4–7 дней [Г].
- **Старое** — дольше; расписание по FSRS (пакет `fsrs`), целевая вероятность вспомнить 0,9 (параметр) [Г]. При переходе в «Старое» состояние FSRS вычисляется по всей истории попыток единицы.

### Как приложение выставляет оценку [Р]

| Исход попытки | Оценка FSRS |
|---|---|
| Голосом, чисто, без подсказок | «Хорошо» |
| Голосом, чисто, дважды подряд с интервалом и быстрее личного среднего | «Легко» |
| Голосом, с самоисправлением или одной подсказкой | «Трудно» |
| Подтверждённая ошибка или две и больше подсказок | «Забыл» |
| Самопроверка: вспомнил / с трудом / не вспомнил | «Хорошо» / «Трудно» / «Забыл»; «Легко» недоступно |
| Не удалось проверить | Оценки нет, срок не сдвигается |
| Ошибка оспорена | Оценки нет, «нужна повторная проверка» |
| Чтение в режиме «с поддержкой» (текст виден) | Оценки нет; состояние «ознакомился» или «с помощью» |
