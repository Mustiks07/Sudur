# 9. Экраны и дизайн

Список экранов и правила внешнего вида. Сами макеты — отдельная работа: они делаются до этапов 4–6 (раздел 7.1) и проверяются на 5–8 людях из целевой аудитории до разработки экранов.

## 9.1 Карта экранов

**Нижнее меню [Р]:** Сегодня · Мусхаф · Учусь читать · Прогресс · Ещё.

| Экран | Что на нём | Требования |
|---|---|---|
| **Старт** | Язык → путь → знакомые суры и время (или входное упражнение курса) → предложение загрузить модель | СТ-01…СТ-09 |
| **Сегодня** | Занятие на сегодня: «около N минут», шаги с причинами, кнопка «Начать»; после занятия — итог и «на сегодня готово». При перерыве — «С возвращением» | ПЛ, ВЗ |
| **Чтение** | Страница мусхафа в одном из трёх режимов; подсказки; индикатор звука; пауза; переключатель мягкого и строгого поведения | ЭЧ, МУ-04, МУ-05 |
| **Разбор** | Итог отрывка, список событий, прослушивание, «Не согласен», «Потренировать это место», «Поделиться итогом» | РБ |
| **Упражнение** | Шаги упражнения на трудное место, переход, похожие аяты | УП |
| **Заучивание нового** | Шаги ЗН-01: слушать → с поддержкой → вспомнить → проверить себя | ЗН |
| **Самопроверка** | Вспомнить → открыть → оценить | СП |
| **Мусхаф** | Страницы, навигация по суре, джузу, странице; плеер чтеца; меню слова | МУ, АУ |
| **Учусь читать** | Путь из этапов, следующий урок | УЧ-01 |
| **Урок** | Шаги урока по одному на экран, мини-проверка | УЧ, ТД |
| **Справочник таджвида** | Правила, примеры со звуком | ТД-02 |
| **Прогресс** | Карта памяти по сурам и страницам; экран суры | КП |
| **Подписка** | Что даёт подписка, цена в тенге, пробный период, восстановление покупок | ПК, раздел 6.4 |
| **Ещё** | Настройки, напоминания, загрузки, данные (выгрузка, удаление), «Помочь улучшить проверку», «Сообщить о проблеме», «Источники и лицензии» | НС, НП, СБ, ПР-01 |

## 9.2 Правила дизайна [Р]

- **Спокойно.** Без конфетти, очков, громких звуков и красного по каждому поводу. Это занятие Кораном, а не игра. Серии дней и достижения — спокойные, без соревнования (раздел 16.4).
- **Тема — токенами.** Все цвета, шрифты и отступы задаются токенами темы, чтобы полный дизайн можно было сменить позже без переделки логики (раздел 16.13).
- **Арабский текст главный.** На экране чтения ничего не перекрывает страницу; кнопки — внизу, крупные, под большой палец.
- **Состояние не только цветом.** Каждое состояние слова отличается значком или начертанием (МУ-05): люди с нарушением цветового зрения и ночной режим.
- **«Не расслышал» — не ошибка.** Нейтральный цвет, мягкий текст; красный — только для подтверждённых ошибок.
- **Честность.** Приложение прямо говорит, что проверяет слова, а не таджвид (ЭЧ-08).
- **Ночной режим** с первого дня.
- **Одна главная кнопка на экране.** Человек с 10 минутами не должен выбирать между пятью вариантами.
- **Окно подписки не появляется при каждом запуске** — только при попытке открыть платное. Это одна из жалоб на Tarteel.
- **Справа налево** — только арабский текст; интерфейс на русском, казахском и узбекском — слева направо.
