# lessons

Движок уроков курса «Учусь читать» и формат пакета уроков. Чистый Dart, без Flutter и без звука.

- **Владелец:** Opus
- **Задача:** [K01](../../docs/tasks/K01-lessons.md)
- **ТЗ:** 3.1 (УЧ-01…УЧ-10), 3.2 (ТД-03), 4.9, 11.2, 12.3, 12.4 (`quizPassPercent`), 16.3 (языки), 16.9

Правила: [`AGENTS.md`](../../AGENTS.md). Публичный интерфейс — только `lib/lessons.dart`; внутренности — в `lib/src/`.

**Содержание уроков движок не пишет и не придумывает.** Буквы, слоги, объяснения, звуки и разметку правил даёт пакет, который делают люди (УЧ-09, УЧ-10, ТД-04, МС-02). Слова Корана в шагах — только номера слов; сам текст берётся из канонической базы.

## Как пользоваться

```dart
final package = switch (parseLessonPackage(json)) {
  Ok(:final value) => value,
  Error(:final error) => ..., // LessonFormatException: путь в JSON и причина
};
final states = lessonStates(package, savedProgress, stageOpen: true);

final engine = LessonEngine(params: LessonParams.defaults, clock: clock);
var run = engine.start(lesson, states[lesson.id]!) ...;  // Result<LessonRun>
final t = engine.answer(run, const Choice('...'));        // Result<LessonTransition>
// t.run — новое состояние, t.events — события для базы и плана
engine.progress(run, contentVersion: package.version);    // строка lesson_progress
```

Всё неизменяемое: каждый вызов принимает `LessonRun` и возвращает новый. Время — внедрённые часы, случайность (выбор вопросов повторения навыка) — внедрённый `Random`.

## Формат пакета (версия 1)

Один пакет — один этап курса. Окончательная схема наброска из ТЗ 4.9:

```json
{
  "format": 1,
  "kind": "lessons",
  "packageId": "stage1-letters",
  "version": "1.0.0",
  "stage": 1,
  "title": {"ru": "…", "kk": "…", "uz": "…", "en": "…"},
  "lessons": [
    {
      "lessonId": "stage1-letters-01",
      "title": {"ru": "…", "kk": "…", "uz": "…", "en": "…"},
      "skills": ["letter:alif", "letter:ba"],
      "steps": [
        {"id": "s1", "type": "explain", "text": {…}, "image": "img/ba.png", "audio": "aud/ba.ogg"},
        {"id": "s2", "type": "hearAndChoose", "skills": ["letter:ba"],
         "audio": "aud/ba.ogg", "options": ["…", "…", "…"], "answer": "…"},
        {"id": "q", "type": "quiz", "stepIds": ["s2"]}
      ]
    }
  ]
}
```

Отличия от наброска ТЗ 4.9:

- мини-проверка — **шаг** `quiz` (как в таблице ТЗ 11.2), последний в уроке, а не отдельное поле урока; `passPercent` у неё необязателен — по умолчанию `quizPassPercent` из пакета `config`;
- тексты — на **четырёх** языках (`ru`, `kk`, `uz`, `en`; ГЛ-01), а не на трёх;
- у шага есть необязательный список `skills` — по нему выбираются вопросы повторения навыка (ТЗ 11.2: «помеченных этим навыком»);
- слова Корана — строкой `сура:аят:слово`, как `WordKey` в `contracts`.

### Поля шагов (ТЗ 11.2)

| `type` | Поля | Результат |
|---|---|---|
| `explain` | `text`, `image?`, `audio?` | `Viewed` |
| `listen` | `audio`, `highlight` | `Listened` |
| `repeatAndCompare` | `audio` | `SelfAssessed` (получилось / не совсем) |
| `hearAndChoose` | `audio`, `options[]`, `answer` | `Answered` (верно / неверно) |
| `seeAndChoose` | `prompt`, `optionsAudio[]`, `answer` | `Answered` |
| `pairDiscriminate` | `audio`, `pair[2]`, `answer` | `Answered` |
| `findForm` | `letter`, `position` (`initial` / `medial` / `final` / `isolated`), `options[]`, `answer` | `Answered` |
| `buildSyllable` | `target`, `pieces[]` (лишние кусочки — отвлекающие) | `Answered`: кусочки в выбранном порядке дают `target` |
| `readSupported` | `from`, `to`, `offerMemorize?` | `SupportedReadingDone`; при `offerMemorize` — событие `MemorizeSuggested` (УЧ-07) |
| `findRule` | `from`, `to`, `rule`, `answerWords[]` | `RuleFound`: доля найденных; как вопрос верно, только если найдены все слова и нет лишних — иначе «нажать всё» проходило бы |
| `quiz` | `stepIds[]`, `passPercent?` | `QuizScored`: процент |
| `speakAndCheck` | `audio`, `target` | Заглушка до испытания И-5: без автоматической проверки — самооценка, как `repeatAndCompare` (МС-04); с проверкой — вердикт приложения `PronunciationChecked` |

### Строгий разбор

`parseLessonPackage` никогда не бросает исключение: испорченный пакет даёт `LessonFormatException` с путём в JSON (`$.lessons[0].steps[3].answer`) и причиной. Ошибки:

- неизвестное или отсутствующее поле, неверный тип, пустая строка, нет одного из языков;
- неподдерживаемая версия формата;
- повтор идентификатора урока или шага;
- ответ не из вариантов, меньше двух вариантов, повтор варианта, в паре не два элемента;
- `target` нельзя собрать из `pieces`;
- путь к файлу выходит из пакета: абсолютный, с `..`, `\` или `:`;
- мини-проверка не последняя или спрашивает шаг без правильного ответа;
- номер слова вне диапазона, диапазон задом наперёд, слово правила вне диапазона.

`LessonPackage.todoPaths` — где ещё стоит `TODO_CONTENT`; при них `isReleaseReady == false`. Не пускать такой пакет в выпуск — проверка `content_build` (ТЗ 4.9). `LessonPackage.media` — все файлы пакета, на которые ссылаются шаги: их наличие проверяет установщик (`content`).

## Состояния урока (ТЗ 11.2)

```text
locked → available → inProgress(шаг) → quiz → passed
                                 quiz ↘ failed → inProgress (трудные шаги) → quiz
```

- **Открытие** (`lessonStates`): урок с сохранённым прогрессом сохраняет состояние. Без прогресса — `available`, если это первый урок открытого этапа (`stageOpen`), если пройден предыдущий урок или если входное упражнение (СТ-05) поставило старт на этот урок или дальше (`placementStart`). Уроки, открытые входным упражнением, не считаются пройденными: навыки даёт только прохождение.
- **Трудные шаги**: вопросы с неверным ответом — и в шагах, и в мини-проверке, — а также самооценка «не совсем». После неудачи `retry` проводит по ним и снова даёт мини-проверку целиком.
- **Мини-проверка (УЧ-04)**: процент верных ответов; урок пройден, если процент ≥ порога. Сравнение без деления: 4 из 5 при 80 % проходит точно.
- **Урок без мини-проверки** пройден после последнего шага.
- **Повтор пройденного урока** не снимает «пройден» и не даёт навыки второй раз; `progress` возвращает `null` — сохранённый прогресс не трогать.
- **Сохранение** — строка `lesson_progress` (ТЗ 12.1): состояние, номер шага, процент, версия пакета. Если версия пакета сменилась, незаконченный урок начинается заново. Список трудных шагов в этой строке не хранится, поэтому после перезапуска повтор проваленного урока идёт по всем шагам.

## События

| Событие | Когда |
|---|---|
| `LessonStepCompleted` | Каждый шаг и итог мини-проверки (ТЗ 4.5) |
| `RecordingNoLongerNeeded` | Шаг с записью закончился, а человек её не сохранил, или человек ушёл с этого шага (`leave`). Приложение удаляет запись из памяти (УЧ-06). Сам звук движок не получает и не хранит |
| `QuizFinished` | Конец мини-проверки: процент, порог, трудные шаги |
| `LessonPassed` | Урок пройден |
| `SkillsLearned` | Урок пройден впервые: из навыков приложение создаёт единицы плана вида `skill` (УЧ-05; планировщик — PL01) |
| `MemorizeSuggested` | После чтения с поддержкой, если в шаге `offerMemorize` (УЧ-07) |

## Повторение навыка (ТЗ 11.2)

`SkillReviewer.start(skill, packages)` выбирает случайно (внедрённый `Random`) до `skillReviewQuestions` вопросов типов `hearAndChoose`, `seeAndChoose`, `pairDiscriminate`, `findRule`, помеченных навыком. Если помеченных вопросов меньше — спрашивает все; если их нет — ошибка `NoReviewQuestions`. Оценка `SkillGrade`: все верно — «Хорошо», одна ошибка — «Трудно», больше — «Забыл». Перевести её в оценку FSRS планировщика — задача приложения.

## Тесты

`test/` — 97 тестов на тестовом пакете `packages/testing/fixtures/lessons_test_stage1.json` (только заглушки):

- каждый тип шага: верный и неверный ответ, ответ не того вида;
- состояния урока: прохождение, порог мини-проверки (80 % проходит, 60 % — нет; свой порог пакета), неудача и повтор трудных шагов, запись «Повтори и сравни», повтор пройденного урока, сохранение и продолжение;
- открытие уроков;
- повторение навыка: выбор вопросов и оценки;
- 30 видов испорченного пакета — понятная ошибка с путём, а не падение.

## Не сделано и вопросы

- **Расхождение с `storage` (O04):** там состояния `lesson_progress` — `locked / available / inProgress / completed`, а в ТЗ 11.2 — ещё `quiz`, `passed`, `failed`. Движок следует ТЗ 11.2. Нужно согласовать (Астра).
- `LessonStepCompleted` в ТЗ 4.5 перечислено среди событий договора, но в `contracts` его нет. Пока событие объявлено здесь; перенос в `contracts` — только через ADR.
- Проверка «в выпускном пакете нет `TODO_CONTENT`» — в `content_build`; движок только даёт `todoPaths`.
- «Произнеси, приложение проверит» — только интерфейс: распознавание зависит от испытания И-5.
- Порядок вариантов ответа движок не перемешивает: это забота экрана.
