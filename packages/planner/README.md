# planner

Чистый Dart-планировщик повторений и занятия на сегодня. Пакет не зависит от
Flutter и базы данных: модели неизменяемы, время приходит через `Clock`, а
случайность — через переданный `Random`.

Публичный интерфейс находится в `lib/planner.dart`. Он включает:

- переходы отрывков, трудных мест и навыков;
- таблицу оценок попытки и FSRS-сроки;
- план на сегодня с бюджетом, долгом, причинами и дополнительным повторением;
- обучение новому, восстановление после перерыва и карту памяти;
- сессии по произвольному диапазону слов.

Все продуктовые пороги собраны в `PlannerParams`. `PlannerParams.defaults`
соответствует ТЗ 12.4 и явным правилам ТЗ 3.4–3.6 и 11.1. Конфигурацию можно
переопределить через `PlannerParams.fromJson`.

## Зависимость FSRS

Используется `fsrs: 2.0.1`: это реализация требуемого ТЗ алгоритма FSRS без
Flutter и базы. Версия закреплена. Лицензия MIT разрешает использование и
распространение при сохранении уведомления об авторских правах. Встроенный
fuzzing отключён, поэтому планирование детерминировано; случайный выбор для
диагностики и восстановления использует только внедрённый `Random`.

## Явные параметры для неоднозначных правил

ТЗ не задаёт численное значение минимального интервала для оценки «Легко» и
соотношение весов диагностической выборки. Поэтому они не зашиты в алгоритм:
`easyMinIntervalDays` по умолчанию равен 1, а `diagnosticBaseWeight`,
`diagnosticStalenessWeight` и `diagnosticErrorWeight` — 1. Владелец может
изменить эти значения без изменения кода. Число сильных и чистых попыток и
календарное окно «вчера» также представлены отдельными параметрами, а не
зашиты в переходы.

```sh
dart format --output=none --set-exit-if-changed lib test
dart analyze

```
