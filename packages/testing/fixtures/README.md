## Атрибуция

Текст Корана в обоих файлах (`textUthmani`, слова в `ayahs`) — дословная копия текста Tanzil (https://tanzil.net), лицензия CC BY 3.0, изменять текст нельзя. Слова — это куски текста аята между пробелами; знак паузы, стоящий в Tanzil отдельно, присоединён к предыдущему слову вместе с пробелом, так что слова аята, соединённые пробелом, дают исходный текст байт в байт.

Разметка страниц и коды знаков — KFGQPC V2 через API Quran.com / QUL; условия использования ещё не подтверждены (ТЗ 6.1).

Полное уведомление Tanzil — в поле `contentVersion.textNotice` файла и в [`tools/content_build/ATTRIBUTION.md`](../../../tools/content_build/ATTRIBUTION.md).

## Тестовый пакет уроков

`lessons_test_stage1.json` — **не содержание курса**. Все тексты — `TODO_CONTENT`; буквы, слоги и варианты ответа — заглушки вида `TODO_CONTENT:letter:ba`; файлы звуков и картинок не существуют. Арабского текста в нём нет.

Слова Корана в шагах `readSupported` и `findRule` указаны только номерами (`78:1:1`). Правило `rule:placeholder` и слово `78:2:2` как «слово с правилом» выбраны произвольно: это **не** разметка таджвида. Настоящая разметка берётся только из источника с правами или из акта разметки преподавателя (ТД-04).
