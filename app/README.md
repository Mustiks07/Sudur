# Sudur app

Flutter-приложение Sudur. Архитектура следует официальному руководству Flutter:
экраны и `ChangeNotifier`-модели находятся в `lib/ui`, хранилища — в
`lib/data/repositories`, навигация — в `lib/routing`, сборка зависимостей — в
`lib/config`.

## Варианты сборки

- `lib/main_dev.dart` — разработка;
- `lib/main_beta.dart` — закрытое тестирование;
- `lib/main_prod.dart` — магазины.

## Прототип P08

Сборка `main_dev.dart` сразу открывает прототип суры 78. Экран использует
`mushaf_view`, получает только `SessionEvent` и управляется через
`ReadingViewModel`. До слияния S05 подключена подставная сессия; она остаётся
для тестов. Точка замены — `PrototypeReadingSessionFactory`.

При первом запуске `PrototypeAssetInstaller` скачивает закреплённую модель
small, канонический JSON из результата P03 и шрифты страниц 582–583. Каждый
файл проверяется по размеру и SHA-256, затем модель повторно проверяется
`asr_sherpa`. Файлы не входят в git и APK.

Внешняя зависимость `crypto: 3.0.6` используется только для SHA-256; лицензия
BSD-3-Clause. Модели имеют MIT, статус лицензии страничных шрифтов остаётся
неподтверждённым согласно ТЗ 6.1, поэтому прототип предназначен для закрытой
проверки.

Инструкция владельцу и сценарии НФ-10, НФ-12, НФ-13 и НФ-18 находятся в
[`docs/prototype.md`](../docs/prototype.md).

## Текст Корана и план

Для единиц плана приложение берёт позиции аятов и отрывков из канона:
`InstalledCanonService` скачивает через `PrototypeAssetInstaller` текст всего
Корана (`packages/testing/fixtures/quran_text.json`, Tanzil без изменений,
ADR 0004) и отрывки по умолчанию (`derived.json`, D01) по закреплённым
коммитам репозитория с проверкой SHA-256. Это временно: по решению владельца
(24.11.2026) на пакет `text` через подписанный манифест (O05, ТЗ 4.9)
переключимся, когда появится сервер пакетов.

«Короткие суры с конца Корана» начинаются с суры 114 и идут к началу Корана
(ТЗ ЗН-05, СТ-09): при старте создаются отрывки суры 114, следующие суры
добавляет заучивание нового (Q11). Суры без разметки страниц читаются во
временном текстовом виде (Q7).
